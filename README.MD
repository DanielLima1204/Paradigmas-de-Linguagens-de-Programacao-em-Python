# 📚 Paradigmas de Linguagens de Programação em Python

## Sobre o repositório

Este repositório foi criado com fins **exclusivamente educacionais** para armazenar os conteúdos, exemplos, exercícios e atividades desenvolvidos durante a disciplina **Paradigmas de Linguagens de Programação em Python**, do curso de **Análise e Desenvolvimento de Sistemas**.

Seu principal objetivo é servir como um ambiente de estudo, consulta e acompanhamento da minha evolução ao longo da disciplina, reunindo os conceitos apresentados em sala de aula e as soluções desenvolvidas durante as atividades práticas.

Este repositório **não representa um projeto de produção**, mas sim um registro organizado do processo de aprendizagem dos diferentes paradigmas de programação utilizando a linguagem Python.

---

## Objetivos

* Organizar todo o conteúdo estudado durante a disciplina.
* Registrar exemplos apresentados em aula.
* Armazenar exercícios propostos e suas respectivas soluções.
* Consolidar os conceitos relacionados aos paradigmas de programação.
* Utilizar o Git e o GitHub como ferramentas de versionamento e documentação da evolução dos estudos.
